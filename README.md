# Desafio Korp

Repositório dedicado ao teste técnico da vaga de DevOps da Korp.
Um serviço HTTP em Go executado em containers atrás de um proxy reverso NGINX, com um monitoramento via Prometheus e Grafana. Todo ambiente é provisionado por um único comando Ansible.

## Requisitos
 - python3
 - ansible-core => 2.15
